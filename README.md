# 30-Day Hospital Readmission Risk — Full-Stack App

Pratham Gupta · B.Tech CSE (AI & DS), IIIT Manipur

Notebook pipeline turned into a deployable app: **ML training script → FastAPI backend → web frontend**.

## Structure
```
ml/common.py        data generator + feature engineering (shared by train & serve)
ml/train.py         compares 6 models, tunes XGBoost, picks F1 threshold, saves artifacts
backend/main.py     FastAPI: /api/predict, /api/metrics, /api/metadata, /api/health
frontend/index.html single-page UI served by the backend at /
Data_Science_Project.ipynb   original analysis / EDA notebook
```

## Run
```bash
pip install -r requirements.txt
python ml/train.py                       # creates backend/artifacts/{model.joblib,metrics.json}
uvicorn backend.main:app --reload        # open http://127.0.0.1:8000  (docs at /docs)
```

## API
`POST /api/predict` with patient JSON → `{probability, risk_tier, flagged, drivers[]}`
(drivers = per-patient XGBoost feature contributions).

## Results
Metrics shown in the app and in `backend/artifacts/metrics.json` are generated by `train.py`;
quote those, not hand-written numbers. Data is synthetic — not for clinical use.
